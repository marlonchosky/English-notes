# Interrogative Words and Morphosyntactic Shifts

Interrogative words (commonly termed **$Wh$-words**) are closed-class functional operators used to encode interrogative force, bind operator variables, and construct direct or indirect questions. 

Rather than belonging permanently to a single part of speech, several core $wh$-items exhibit systematic **morphosyntactic category shifts** across **Determiners ($D^\circ$)**, **Pronouns ($NP$ Heads)**, and **Adverbs ($Adv^\circ$)**, dictated by internal phrasal projection and head-complement licensing.

---

| :----------------- | :--------------------------------: | :-----------------------------: | :------------------------------: | :----------------------------------------------------------- |
| **What**           |              **YES**               |             **YES**             |               ❌ NO               | Entity identification, entity classification, open/unbounded domains |
| **Which**          |              **YES**               |             **YES**             |               ❌ NO               | Selective identification over bounded/closed sets            |
| **Whose**          |              **YES**               |             **YES**             |               ❌ NO               | Genitive/possessive dependency over nominal entities         |
| **Who / Whom**     |                ❌ NO                |             **YES**             |               ❌ NO               | Animate entity argument (Nominative / Accusative)            |
| **Where**          |                ❌ NO                |              ❌ NO               |             **YES**              | Locative coordinate / spatial trajectory vector              |
| **When**           |                ❌ NO                |              ❌ NO               |             **YES**              | Temporal coordinate / time frame anchor                      |

| **How**            |                ❌ NO                |              ❌ NO               |             **YES**              | Manner operator or degree operator inside $AP$/$AdvP$/$DP$ containers |

## 2. The Nominal Shift: Determiner ($D^\circ$) vs. Pronoun ($NP$ Head)

The nominal interrogatives (`what`, `which`, `whose`) project differently depending on whether an overt nominal complement is selected:

```text
Nominal Interrogative Realizations
├── A. Interrogative Determiner (D°):
│      Projects as a functional specifier/head selecting an overt NP complement.
│      • [DP [D° Which] [NP microservice]] crashed?
│      • [DP [D° What] [NP database]] do you recommend?
│      • [DP [D° Whose] [NP pull request]] broke the build?
│
└── B. Interrogative Pronoun (NP Head / Intransitive DP):
       Projects as an independent argument head without an overt noun.
       • [DP Which] of these microservices crashed?
       • [DP What] did the architect recommend?
       • [DP Whose] is this unassigned ticket?
```

### A. Interrogative Determiner ($D^\circ$) Frame
When directly introducing an overt nominal, the $wh$-word sits in the functional determiner position ($D^\circ$):
* *"**Which** database cluster failed?"* ($D^\circ$ modifying lexical noun *database cluster*)
* *"**What** protocol does this API employ?"* ($D^\circ$ modifying lexical noun *protocol*)
* *"**Whose** credentials triggered the deployment?"* ($D^\circ$ occupying the genitive specifier/head position)

### B. Interrogative Pronoun ($NP$ Head) Frame
When the nominal complement is elided, inherently represented, or partitively selected via an *of*-phrase, the $wh$-word serves as the sole structural nominal head:
* *"**What** did the logs reveal?"* (Direct Object argument of *reveal*)
* *"**Which** of the candidate nodes is active?"* (Structural head of the partitive $DP$)
* *"**Whose** is this workstation?"* (Predicate possessive nominal head)

## 3. Generative Syntax vs. Traditional Grammar

Traditional pedagogical grammars frequently label words like *what*, *which*, and *whose* as **"Interrogative Adjectives"** when they appear before nouns. Modern generative grammar rejects this classification for three structural reasons:

### 1. Degree Modification Ban
True adjectives ($A^\circ$) license degree adverbs in their specifier position ($\text{Spec, AP}$), such as *very*, *too*, or *extremely*. Interrogative determiners strictly bar degree modification:
* ✅ *A **very critical** database.* (True Adjective)
* ❌ *\*A **very what** database?* (Crash: $D^\circ$ cannot host degree specifiers)
* ❌ *\*The **extremely which** cluster?* (Crash)

### 2. Central Determiner Stacking Ban
Central determiners occupy the same structural layer ($D^\circ$) and cannot stack. If *what* or *which* were true adjectives, they would freely follow central articles (*the*, *a/an*):
* ✅ *The new cluster.* (Central Article + Attributive Adjective)
* ❌ *\*The **what** cluster did you test?* (Crash: Double $D^\circ$ insertion violates the Determiner Phrase template)
* ❌ *\*A **which** system failed?* (Crash)

### 3. Predicative Position Blocking
Descriptive adjectives occur freely in predicative Subject Complement positions. Interrogative determiners cannot be parsed as predicative adjectives:
* ✅ *The database is **fast**.* (Predicative $AP$)
* ❌ *\*The database is **which**?* (Ungrammatical except as an echo-question seeking a missing noun: *"The database is which one?"*)

## 4. Domain Selection: Bounded vs. Unbounded Operators

The semantic choice between `which` and `what` is governed by **Domain Boundedness**:

| Interrogative Operator | Domain Boundary Status   | Pragmatic Set Definition                                     | Diagnostic Context                                           |
| :--------------------- | :----------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **`Which`**            | **Bounded / Closed Set** | Restricted to a known, contextually salient, or explicitly enumerated set of alternatives. | *Selecting from predefined dropdown items, known servers, or limited options.* |
| **`What`**             | **Unbounded / Open Set** | Operates over an open, infinite, or completely unspecified domain of entities. | *Open-ended exploratory queries, general definitions, or unknown categories.* |

### Diagnostic Case Studies
* **Bounded Set ($N$ is finite & identifiable):**
  * *"**Which** cloud provider did we select: AWS or GCP?"* (Closed set of 2 $\longrightarrow$ `Which` is mandatory)
  * *"**Which** of these three builds passed tests?"* (Explicitly bounded partitive $\longrightarrow$ `Which`)
* **Unbounded Set ($N$ is infinite or unspecified):**
  * *"**What** programming languages do you know?"* (Open domain $\longrightarrow$ `What` is canonical)
  * *"**What** caused the container memory leak?"* (Unspecified error universe $\longrightarrow$ `What`)

## 5. Structural Realization of "Whose": Determiner vs. Pronoun Syntax

The genitive interrogative `whose` exhibits a distinct stylistic and structural asymmetry between its Determiner and Pronoun frames:

```text
Structural Alternation of 'Whose'
├── 1. Interrogative Determiner Frame (Natural / Preferred):
│      [CP [DP Whose commit]_i [C' did_j [TP you review t_i]]]
│      • Direct information packaging: "Whose commit did you review?"
│
└── 2. Interrogative Pronoun Frame (Predicate Inverted / Formal):
       [CP [NP Whose]_i [C' is_j [TP [DP this commit] t_j t_i]]]
       • Formulaic copular predication: "Whose is this commit?"
```

* **Stylistic Profile:** The Determiner construction (*"Whose code is this?"*) is vastly preferred in technical and conversational registers because it keeps the interrogative operator and its referent noun packaged within a unified $DP$ container before movement occurs.
* **Agreement Implication:** In the pronoun frame (*"Whose are these keys?"* vs. *"Whose is this key?"*), the copular verb agrees not with *whose*, but with the post-verbal demonstrative subject phrase.

## 6. Prepositional Phrases and Pied-Piping Architectures

When an interrogative determiner operates inside a prepositional phrase ($PP$), modern syntax distinguishes between the **operator head**, its **nominal complement**, and the **maximal projection**:

$$\mathbf{\text{[PP [P}^\circ\ \text{To]} \quad \mathbf{\text{[DP [D}^\circ\ \text{what]} \quad \mathbf{\text{[NP [N}^\circ\ \text{extent]]]]}} \quad \text{did the service optimize query execution?}$$

### Phrasal Breakdown: "To what extent"
1. **`To` ($P^\circ$):** Functional Preposition heading the entire maximal projection ($PP$).
2. **`what` ($D^\circ$):** Interrogative Determiner acting as the functional specifier/head of the nominal phrase.
3. **`extent` ($N^\circ$):** Head Noun serving as the Object of the Preposition within the $DP$.
4. **Entire Container (`To what extent`):** Syntactically a **Prepositional Phrase ($PP$)** operating functionally within the matrix clause as an **Adverbial of Degree or Measure**.

### Extraction Mechanics: Pied-Piping vs. Stranding
* **Pied-Piping (Formal / Academic):**  
  The interrogative operator drags the entire prepositional container to $\text{Spec, CP}$:  
  $$\text{[CP [PP \textbf{To what extent}}]_i \text{ did you optimize the queries } t_i\text{?]}$$
* **Preposition Stranding (Informal / Colloquial):**  
  The $DP$ operator extracts alone, stranding the preposition $P^\circ$ at its base-generated site inside the $VP$:  
  $$\text{[CP [DP \textbf{What extent}}]_i \text{ did you optimize the queries [PP to } t_i\text{]?]}$$

## 7. Syntax Guardrails & Crash Rules

### Guardrail 1: The "How" Word-Class Prohibition
`How` is exclusively a **Degree or Manner Adverb ($Adv^\circ$)**[cite: 8]. It can **never** function as a Determiner ($D^\circ$), Pronoun ($NP$), or Noun[cite: 8]. It cannot modify a noun directly without an intervening scalar adjective or quantifier[cite: 7, 8]:
* ❌ *\*How database did you deploy?*[cite: 7]
* ✅ *Which / What database did you deploy?*[cite: 7]
* ✅ *How large a database did you deploy?* ($How$ modifies adjective $large$ inside an inverted degree $DP$ container)[cite: 5, 20]

### Guardrail 2: The "Who" Determiner Prohibition
`Who` and `whom` are strictly **Interrogative Pronouns** encoding personhood arguments[cite: 7]. They cannot function as determiners[cite: 7]:
* ❌ *\*Who script caused the pipeline failure?*[cite: 7]
* ✅ *Whose script caused the pipeline failure?* (Genitive Determiner)[cite: 7]
* ✅ *Which script caused the pipeline failure?* (Selective Determiner)[cite: 7]

### Guardrail 3: Demonstrative-Interrogative Stacking Crash
Interrogative determiners cannot co-occur with demonstratives (*this, that, these, those*) inside the same $DP$ container[cite: 5]:
* ❌ *\*Which this server should we restart?*
* ✅ *Which of these servers should we restart?* (Partitive Pronoun Structure)
* ✅ *Which server should we restart?* (Direct Determiner Frame)
