# Resultatives (Secondary Predicates)

A **Resultative** is a secondary predicate that denotes a terminal state, boundary, or endpoint resulting from the event expressed by the primary verb. 

Unlike depictives (which describe a state existing *during* the action), resultatives describe the *consequence or culmination* of the event.

---

## 1. Syntactic Realizations of Resultatives

Resultative endpoints are not restricted to Adjective Phrases. In modern syntax, they are realized across three primary syntactic categories:

1. **Adjective Phrases (AP):**
   - *He hammered the metal **flat**.*
   - *The river froze **solid**.*
2. **Prepositional Phrases with Objects (Transitive PP):**
   - *The vase broke **into pieces**.*
   - *The baby cried himself **to sleep**.*
3. **Particles / Intransitive Prepositions (Bare PP / P°):**
   - *The river dried **up**.*
   - *The building burned **down**.*
   - *He tore the poster **down**.*

---

## 2. Transitive Resultatives (Complex Transitive Verb Frame)

In transitive causative structures where an agent causes an entity to reach a bounded terminal state, the verb shifts into a **Complex Transitive Verb (CTV)** frame. The secondary predicate occupies the direct predicative slot, functioning as an obligatory **Resultative Object Complement**:

$$\text{Subject (Agent)} + \text{CTV} + \text{Direct Object (Patient)} + \text{Resultative Object Complement}$$

### A. Adjective Phrase Complements (Bare Property Result)
When the result denotes a property change directly characterizing the object:
- *He licked the plate **clean**.*
  - **Syntax:** *licked* = CTV; *the plate* = DO; *clean* = Resultative Object Complement (AP).
- *They painted the door **red**.*
  - **Syntax:** *painted* = CTV; *the door* = DO; *red* = Resultative Object Complement (AP).
- *He hammered the metal **flat**.*
  - **Syntax:** *hammered* = CTV; *the metal* = DO; *flat* = Resultative Object Complement (AP).

### B. Particle / Intransitive Preposition Complements ($P^\circ$)
In transitive verb-particle constructions where the particle establishes the culminated terminal state or orientation of the direct object:
- *He tore the building **down**.*
  - **Syntax:** *down* is an intransitive preposition ($P^\circ$) heading a bare PP that functions as a **Resultative Object Complement**. (Terminal state: $[ \text{building} \rightarrow \text{demolished/collapsed} ]$).
- *She wiped the moisture **off**.*
  - **Syntax:** *off* ($P^\circ$) functions as the **Resultative Object Complement** establishing the final detached location/state of the moisture.

### C. Optional Transitive Results (Resultative Adjuncts)
When a monotransitive action is already complete and saturated on its own, an extra prepositional path expressing the degree of finish acts as an optional **Resultative Adjunct**:
- *He wiped the table **to a shine**.*
  - **Syntax:** *"He wiped the table"* is an intact monotransitive proposition. *to a shine* is a PP specifying an optional resultant degree/finish (Resultative Adjunct).

---

## 3. Intransitive Resultatives (Unaccusative Verbs)

Resultatives can target the grammatical **subject**, but strictly when the verb is **Unaccusative** (where the grammatical surface subject is semantically the Patient/Theme undergoing the state change).

### A. Standalone Unaccusatives + Optional Resultative Adjuncts
When the unaccusative root inherently contains a complete event boundary, an added secondary predicate is grammatically optional:
- *The river froze **solid**.*
  - **Primary Clause:** *"The river froze."* (Complete, grammatical intransitive clause).
  - **Syntactic Role:** *solid* (AP) is an optional **Subject Resultative Adjunct**.
- *The lake water froze **thick**.*
  - **Syntactic Role:** *thick* (AP) is an optional **Subject Resultative Adjunct**.

### B. Complex Unaccusatives + Obligatory Resultative Complements
When the unaccusative verb expresses an open trajectory or incomplete physical state change, the secondary predicate is syntactically mandatory:
- *The door blew **open**.* / *The gate swung **open**.*
  - **Syntactic Role:** *open* (AP) is an obligatory **Resultative Subject Complement** (without it, *"The door blew"* / *"The gate swung"* fails to denote the culminated event).
- *The river dried **up**.*
  - **Syntactic Role:** *up* is a particle / intransitive preposition ($P^\circ$) functioning as an obligatory **Resultative Subject Complement** bounding the desiccating event.

---

## 4. Radical Transitions: The "Into" and "To" PP Rules

When a resultative denotes a complete structural transformation, phase change, or division into parts, English replaces bare adjectives with Prepositional Phrases.

### The "Into" Transition Rule (Obligatory PP Complement)
Radical physical division, material reorganization, or phase transitions demand an obligatory **Prepositional Resultative Complement** headed by *into* followed by a noun phrase ($DP/NP$):
- *The vase broke **into pieces**.* (Physical fragmentation).
- *The ice melted **into water**.* (Phase change).
- *The food turned **into poison**.* (Substance transformation).
- *The caterpillar transformed **into a butterfly**.* (Complete biological metamorphosis).

> ⚠️ **Syntax Guardrail (*Into* vs. Bare AP):**
> Prepositions like *into* strictly subcategorize for a Nominal Phrase ($DP/NP$). Pairing *into* directly with an adjective crashes the derivation:
> - *The engineer hammered the metal **flat**.* ✅ (Bare AP)
> - *\*The engineer hammered the metal **into flat**.* ❌ (Crash: $P^\circ$ requires a DP)
> - *The engineer hammered the metal **into a flat sheet**.* ✅ (Valid: $P^\circ + DP$)

### The "To" Endpoint Rule
When the resultative denotes reaching an abstract physiological condition or natural, bare destination state:
- *The baby cried himself **to sleep**.*
- *They ran themselves **to exhaustion**.*

---

## 5. Unergative Verbs & The "Fake Object" Shift

Unergative verbs (*run, cry, shout, laugh*) are fundamentally agentive intransitive verbs. Because the subject is an active doer rather than a patient undergoing a transition, unergative verbs **cannot** take a resultative directly:
- *\*The runner ran tired.* ❌ (Interpreted as a Depictive: he was tired *while* running, not *as a result* of running).
- *\*The baby cried to sleep.* ❌

### The Reflexive Coercion Frame
To attach a resultative endpoint to an unergative verb, English employs a **"Fake" (Reflexive) Object**. This coerces the intransitive verb into a **Complex Transitive Verb (CTV)** frame, allowing the resultative complement to anchor onto the direct object and reflect back to the agent subject:

$$\text{[Subject]} + \text{[Unergative as CTV]} + \text{[Fake Reflexive DO]} + \text{[Resultative Complement]}$$

- *He ran **himself** **tired**.*
  - *ran* = Coerced CTV; *himself* = Fake Reflexive DO; *tired* = Resultative Object Complement (AP).
- *The baby cried **himself** **to sleep**.*
  - *cried* = Coerced CTV; *himself* = Fake Reflexive DO; *to sleep* = Prepositional Resultative Complement (PP).
- *The protestor shouted **himself** **hoarse**.*
  - *shouted* = Coerced CTV; *himself* = Fake Reflexive DO; *hoarse* = Resultative Object Complement (AP).
- *He cried **himself** **into a frenzy**.*
  - *cried* = Coerced CTV; *himself* = Fake Reflexive DO; *into a frenzy* = Prepositional Resultative Complement (PP).
