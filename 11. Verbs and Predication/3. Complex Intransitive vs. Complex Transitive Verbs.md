# Complex Intransitive vs. Complex Transitive Verbs: Argument Mapping and Complementation

In formal generative syntax, the core structural divergence between a **Complex Intransitive Verb (CIV)** and a **Complex Transitive Verb (CTV)** is governed by **Argument Mapping**:

$$\mathbf{\text{Complex Intransitive Frames:}} \quad \text{The secondary predicate/bound targets the } \mathbf{\text{Subject}}.$$
$$\mathbf{\text{Complex Transitive Frames:}} \quad \text{The secondary predicate/bound targets an } \mathbf{\text{Accusative Direct Object}}.$$

Both verb classes reject simple monotransitive or intransitive closure: omitting their secondary complements triggers an immediate syntactic crash.

---

## 1. Master Structural Comparison

| Feature                       | Complex Intransitive Verb (CIV)                              | Complex Transitive Verb (CTV)                                |
| :---------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| **Syntactic Blueprint**       | $\text{Subj} + V_{\text{CIV}} + \text{Complement}$           | $\text{Subj} + V_{\text{CTV}} + \text{DO} + \text{Secondary Complement}$ |
| **Direct Object Licensed?**   | ❌ **NO** (0 Internal Nominal Objects)                        | ✅ **YES** (Obligatory Accusative $\text{DP}$)                |
| **Target of the Complement**  | Grammatical **Subject** ($\text{DP}$)                        | Grammatical **Direct Object** ($\text{DO}$)                  |
| **Licensed Complement Types** | Adverbial Complement (Loc/Temp), Measure Complement, Subject Complement | Object Complement ($\text{AP}$, Identity $\text{NP}$, Non-finite $\text{VP}$), Locative Adverbial Complement |
| **Passive Transformation**    | ❌ Blocked (No direct object to promote)                      | ✅ Valid ($\text{DO} \longrightarrow \text{Passive Subject}$; $\text{OC} \longrightarrow \text{SC}$) |

## 2. Complex Intransitive Verbs (CIVs) & Copular Systems

Complex Intransitive structures evaluate states, identities, boundaries, or locations strictly relative to the **Subject**. Generative syntax distinguishes two distinct sub-systems:

```text
Subject-Oriented Intransitive Predication
├── A. Copular / Linking Verbs (Attributive / Identity):
│      Act as a relational connector (= or →) linking the Subject to an internal quality.
│      • Sensory / Static: "The deployment pipeline sounds solid." (Subject = solid)
│      • Aspectual / Vector: "The staging node turned unresponsive." (Subject → unresponsive)
│
└── B. True Complex Intransitive Verbs (CIVs - External Spatio-Temporal Bounds):
       Lexical verbs that require an external Adverbial or Measure coordinate to bound the event.
       • Locative Spatial Coordinate:  "The central database resides [PP in the private subnet]."
       • Temporal Duration Coordinate: "The migration process lasted [DP four hours]."
       • Intransitive Measure Scale:   "The server chassis weighs [DP two hundred pounds]."
       • Framework A Locative "Be":     "The cluster is [PP in rack 2]."
```

### Framework A: Locative "Be" as a CIV
Under **Framework A** (adopted across this repository's syntax documentation), when the verb *be* (*is/are/was/were*) asserts physical presence at a mandatory spatial or measure coordinate, it ceases to behave as a pure qualitative copula and operates as a **Complex Intransitive Verb (CIV)**:
* *"The server **is** [PP **in the secondary data center**]."*  
  $\rightarrow$ Deletion test: *\* "The server is"* (Crash: mandatory locative complement omitted).  
  $\rightarrow$ **is:** $\text{CIV}$; **in the secondary data center:** Locative Adverbial Complement ($\text{PP}$).
* *"We **are** [PP [DP three minutes] [P° away] [PP from the office]]."*  
  $\rightarrow$ **are:** $\text{CIV}$; **three minutes away from the office:** Unified Adverbial Complement of Measure and Location ($\text{PP}$).

## 3. Complex Transitive Verbs (CTVs)

A **Complex Transitive Verb** selects an obligatory Direct Object and a secondary predicative element that either characterizes the internal condition of that object (**Object Complement**) or locates it in external space (**Adverbial Complement**).

$$\mathbf{\text{Subject}} + \mathbf{V_{\text{CTV}}} + \mathbf{\text{Direct Object (DO)}} + \mathbf{\text{Secondary Complement}}$$

### A. CTVs with Object Complements (Internal State, Role, or Result)
The complement acts as a secondary predicate over the direct object:

| Object Complement Type        | Realization Frame       | Technical Example                                            | Syntactic Mechanism                                |
| :---------------------------- | :---------------------- | :----------------------------------------------------------- | :------------------------------------------------- |
| **Evaluative / Depictive AP** | Adjective Phrase        | *"The security team considers [DP the build] [AP **unstable**]."* | Attributable mental judgment over the $\text{DO}$. |
| **Resultative AP**            | Adjective Phrase        | *"The script hammered [DP the buffer] [AP **flat**]."*       | Bounded terminal state resulting from the verb.    |
| **Identity / Role NP**        | Nominal Phrase          | *"The review board elected [DP her] [NP **lead architect**]."* | Categorical classification or role assignment.     |
| **Bare Infinitive Phrase**    | Non-Finite $VP$         | *"The lead made [DP the team] [VP **restart the proxy**]."*  | Causative/Perception verb selecting base event.    |
| **To-Infinitive Phrase**      | Infinitival $\text{TP}$ | *"The architect got [DP the engineer] [TP **to deploy the fix**]."* | Catenative causative persuasion frame.             |
| **Participle Phrase**         | Present/Past Participle | *"We heard [DP the disk array] [VP **failing**]."*<br>*"They had [DP the snapshot] [VP **restored**]."* | Ongoing real-time event vs. passive result state.  |

### B. CTVs with Adverbial Complements (External Physical Coordinates)
Unlike Object Complements (which assign an internal quality or identity to the noun), an **Adverbial Complement** places the direct object into an external physical coordinate or bounded perimeter:
* *"The engineer **put** [DP the configuration file] [PP **into the root directory**]."*
  * **put:** $\text{CTV}$
  * **the configuration file:** $\text{Direct Object}$
  * **into the root directory:** Locative Adverbial Complement ($\text{PP}$). *(Crash: \* "The engineer put the configuration file").*
* *"They **placed** [DP the backup archive] [PP **on the offsite server**]."*

## 4. The Functional Separation: CTV vs. Transitive Prepositional Verb

Both constructions surface with the linear sequence $\text{Subject} + \text{Verb} + \text{DP} + \text{PP}$, but their structural architectures diverge:

```text
Linear Surface: [ S + V + DP + PP ]
├── Complex Transitive Verb (CTV):
│   The PP is an Adverbial Complement (Spatial Coordinate) OR Prepositional Object Complement.
│   • "We placed [DP the server] [PP in rack 4]." (Locative Adverbial Complement)
│   • "The crash left [DP him] [PP with the outage report]." (Circumstantial Object Complement)
│
└── Transitive Prepositional Verb (Prepositional Ditransitive):
    The PP is a Prepositional Complement (Oblique Argument) introducing an entity selected by V°.
    • "The company provided [DP the team] [PP with credentials]." (Prepositional Complement)
    • "The firewall protected [DP the cluster] [PP from unauthorized traffic]." (Prepositional Complement)
```

## 5. The Passive Promotion Test (Structural Diagnostic)

Because Complex Intransitive Verbs lack an internal direct object, they **completely reject passive voice transformations**. Conversely, Complex Transitive Verbs freely undergo passivization, where the Direct Object moves to the matrix Subject position ($\text{Spec, TP}$), and the Object Complement shifts into a **Subject Complement**:

### The CTV $\longrightarrow$ Passive Shift
$$\mathbf{\text{Active CTV:}} \quad \text{The review board deemed } [\text{the design}]_{\text{DO}} \ [\text{flawed}]_{\text{OC}}.$$
$$\mathbf{\text{Passive Copular Frame:}} \quad [\text{The design}]_{\text{Subj}} \text{ was deemed } [\text{flawed}]_{\text{SC}} \text{ by the review board}.$$

### The Locative CTV $\longrightarrow$ Passive Shift
$$\mathbf{\text{Active CTV:}} \quad \text{The technician placed } [\text{the server}]_{\text{DO}} \ [\text{in rack 2}]_{\text{Adv Comp}}.$$
$$\mathbf{\text{Passive CIV Frame:}} \quad [\text{The server}]_{\text{Subj}} \text{ was placed } [\text{in rack 2}]_{\text{Adv Comp}} \text{ by the technician}.$$

### Intransitive CIV Crash under Passivization
* Active CIV: *"The database cluster resides in rack 4."*  
  $\rightarrow$ ❌ *\* "Rack 4 is resided by the database cluster."* (Passive crash: zero direct objects).
* Active CIV Measure: *"The test run lasted four hours."*  
  $\rightarrow$ ❌ *\* "Four hours was lasted by the test run."* (Passive crash: Measure Complements cannot be promoted).

## 7. Syntactic Crash Diagnostics

### Diagnostic 1: CIV/CTV Obligatory Coordinate Omission
* ❌ *\*"The systems administrator placed the replacement drive."*
* **Root Cause:** *Place* is subcategorized as a Complex Transitive Verb requiring both an accusative Direct Object and an obligatory Locative Adverbial Complement.
* ✅ **Fix:** *"The systems administrator placed the replacement drive **into the modular bay**."*

### Diagnostic 2: Copular / CIV Aspectual Collision (*Turn* vs. *Turn into*)
* ❌ *\*"The corrupted database partition turned a bottleneck."*
* **Root Cause:** When *turn* takes an identity/noun phrase expressing a radical qualitative transformation, it requires the prepositional path *into*. Without *into*, *turn* cannot map an identity noun.
* ✅ **Fix:** *"The corrupted database partition turned **into** a bottleneck."* (Transformational CIV frame).
* ✅ **Alternative:** *"The corrupted database partition turned **unusable**."* (Copular frame with Adjective Phrase).

### Diagnostic 3: Causative Complementation Selection Violation
* ❌ *\*"The engineering director made the developers **to rewrite** the legacy API."*
* **Root Cause:** In the active voice, the causative CTV *make* strictly selects a bare infinitive phrase, filtering out the infinitival complementizer *to*.
* ✅ **Fix:** *"The engineering director made the developers **rewrite** the legacy API."*

### Diagnostic 4: Passive Promotion of CIV Measure Complements
* ❌ *\*"Two hundred pounds **is weighed** by the enterprise server rack."*
* **Root Cause:** *Weigh* is an intransitive scalar verb; *two hundred pounds* is an Intransitive Measure Complement (quasi-object) rather than a referential accusative direct object, blocking A-movement to subject position.
* ✅ **Fix:** *"The enterprise server rack **weighs two hundred pounds**."*
