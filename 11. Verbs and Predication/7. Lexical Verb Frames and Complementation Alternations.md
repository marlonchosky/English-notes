# Lexical Verb Frames and Complementation Alternations

While the broad classification of verbs (Monotransitive, Ditransitive, Complex Transitive, Unaccusative, Ergative) provides the macro-syntactic architecture of the clause, individual lexical verbs enforce idiosyncratic **Subcategorization Frames** ($c$-selection) and semantic requirements ($s$-selection).

This guide documents the primary lexical verb frames in English where surface syntax shifts dynamically based on the verb's underlying semantic frame.

---

## 1. The Locative Frame Shift: Object Complement vs. Adverbial Complement

Verbs of maintenance, intention, and retention (*keep, want, leave, put*) can select either an internal property (**Object Complement**) or an external spatial coordinate (**Adverbial Complement**).

### A. The "Keep" Frame
* **State / Quality Preservation (Complex Transitive Frame):**
  * *"The monitoring daemon kept [DO the connection] [OC active]."*
  * **Anatomy:** $\text{Subj} + V_{\text{CTV}} + \text{Direct Object} + \text{Object Complement } (AP)$.
  * **Semantics:** Direct small-clause predication ($\text{the connection} \rightarrow \text{active}$).
* **Spatial Retention (Complex Transitive with Locative Complement):**
  * *"The sysadmin kept [DO the cold-storage backups] [AC in the secondary vault]."*
  * **Anatomy:** $\text{Subj} + V + \text{Direct Object} + \text{Locative Adverbial Complement } (PP)$.
  * **Semantics:** Requires an external locative destination/anchor; omitting the PP changes or crashes the frame (*"The sysadmin kept the cold-storage backups"* means *retained/did not discard*).

### B. The "Want" Frame
* **Volitional Non-Finite Proposition:**
  * *"The architect wanted [the service to restart automatically]."*
  * **Anatomy:** Transitive verb taking an ECM / Infinitival complement clause with an overt subject (*the service*).
* **Locative Goal / Directional Requirement:**
  * *"The security lead wants [DO the contractor credentials] [AC out of the database]."*
  * **Anatomy:** $\text{Subj} + V + \text{Direct Object} + \text{Directional Adverbial Complement } (PP)$.
  * **Semantics:** Demands a terminal trajectory or spatial boundary; omission (*"The lead wants the credentials"*) collapses the meaning to simple acquisition.

## 2. The "Help" Alternation Suite

The lexical verb **`help`** exhibits unique syntactic flexibility in English, licensing three distinct complementation patterns without changing its core lexical meaning:

```text
The Complementation Inventory of "Help"
├── 1. Bare Infinitive Complement (ECM / Small Clause):
│      "This tool helps [clean up the cache]."
│      • Direct non-finite VP complement without the "to" marker.
│
├── 2. To-Infinitive Complement:
│      "This tool helps [to clean up the cache]."
│      • Full infinitival non-finite clause.
│
├── 3. Transitive Object + Infinitival Complement:
│      "This tool helps [DO the team] [to / bare refactor the system]."
│      • Licenses an overt beneficiary Direct Object before the non-finite verb.
│
└── 4. Prepositional Alternation:
       "This tool helps [PP in [Gerund clarifying the root cause]]."
       • Oblique prepositional frame headed by "in" + -ing nominal.
```

## 3. Perception and Causative Small Clauses (Bare Infinitives)

A constrained set of causative (*make, let, have*) and sensory perception verbs (*see, hear, watch, notice*) select a non-finite **Bare Infinitive Clause (Small Clause)** rather than a full *to*-infinitive:

| Lexical Class  | Verb Head | Canonical Active Blueprint                                | Example Construction                         | Passive Voice Shift                                          |
| :------------- | :-------- | :-------------------------------------------------------- | :------------------------------------------- | :----------------------------------------------------------- |
| **Causative**  | *make*    | $\text{Subj} + \text{make} + \text{DO} + V_{\text{bare}}$ | *"The deadlock **made the process abort**."* | Re-inserts *to*: *"The process was made **to abort**."*      |
| **Permissive** | *let*     | $\text{Subj} + \text{let} + \text{DO} + V_{\text{bare}}$  | *"The firewall **let the packet pass**."*    | Replaced by *allow*: *"The packet was **allowed to pass**."* |
| **Perception** | *see*     | $\text{Subj} + \text{see} + \text{DO} + V_{\text{bare}}$  | *"The operator **saw the CPU spike**."*      | Re-inserts *to*: *"The CPU was seen **to spike**."*          |
| **Perception** | *hear*    | $\text{Subj} + \text{hear} + \text{DO} + V_{\text{bare}}$ | *"The engineer **heard the fan fail**."*     | Re-inserts *to*: *"The fan was heard **to fail**."*          |

## 4. Inchoative / State-Change Verbs: "Turn", "Go", "Come", "Fall"

English employs specific intransitive lexical verbs to denote state changes, each with strict selectional constraints on the adjectives they license:

* **`turn` (Color, Sensory Decay, or Radical Physical Shift):**
  * *"The food **turned bad**."* / *"The traffic light **turned green**."*
  * Selection: Restricts to physical qualities, colors, and binary states.
* **`go` (Deterioration, Malfunction, or Absence):**
  * *"The milk **went sour**."* / *"The server cluster **went dark**."*
  * Selection: Strongly selects negative or deteriorating physical/mental states (*go bad, go bankrupt, go silent*).
* **`come` (Fulfillment or Realization):**
  * *"The prediction **came true**."* / *"The knot **came loose**."*
  * Selection: Selects positive attainment or physical detachment.
* **`fall` (Passive Surrender / Involuntary State):**
  * *"The operator **fell asleep**."* / *"The node **fell silent**."*
  * Selection: Selects non-volitional psychological and physiological conditions.

## 5. Syntactic Crash Diagnostics

### Diagnostic 1: Inserting "To" with Active Causatives
* ❌ *\*"The manager made the engineers **to work** overtime."*
* **Root Cause:** Active causative *make* c-selects a bare infinitival VP, not a full non-finite TP.
* ✅ **Fix:** *"The manager made the engineers **work** overtime."*

### Diagnostic 2: Dropping "To" under Passive Causatives
* ❌ *\*"The engineers were made **work** overtime."*
* **Root Cause:** Passive transformation on *make* removes the small-clause licensing environment, obligatorily restoring the *to*-infinitive particle.
* ✅ **Fix:** *"The engineers were made **to work** overtime."*

### Diagnostic 3: Selectional Collision on State Change
* ❌ *\*"The build **went green**."* *(In strict canonical grammar; common in slang).*
* **Root Cause:** *Go* canonically selects states of deterioration or failure (*went red*, *went bad*). Positive states and colors select *turn*.
* ✅ **Fix:** *"The build **turned green**."*
